# 圆角相机 UI

[五屏总览](00-圆角相机UI总览.png)

5 张 1920 × 1080 横屏静态原型。取景窗、切换项、按钮和侧栏采用统一的圆角。纸纹和水彩快门延续手绘质感，取景窗显示写实影像。

界面使用功能称呼。顶部「机舱」可打开选择页，以样片和用途区分胶片取景、即时出片、双格合拍和数码直闪。

| 界面 | 功能安排 |
| --- | --- |
| [默认取景](01-默认取景.png) | 取景窗内是对焦和焦段，窗外下沿显示快门速度、ISO 和曝光补偿。右侧保留画幅、网格、闪光、翻转、拍照、相册、胶卷和专业参数。 |
| [换卷预览](02-换卷预览.png) | 试看的胶卷有勾选状态，当前拍摄用卷另外标记。确认后应用，配方有独立入口。 |
| [专业参数](03-专业参数.png) | 展示自动曝光面板。曝光补偿和色温可调，ISO 和快门速度显示读数。界面为切换手动曝光保留入口。 |
| [贴纸识别](04-贴纸识别.png) | 快门位置与普通拍摄一致，取景框标出主体，拍下后进入贴纸预览。 |
| [机舱选择](05-机舱选择.png) | 四种拍摄方式通过示例效果和功能说明区分，标记当前使用的选项。 |
