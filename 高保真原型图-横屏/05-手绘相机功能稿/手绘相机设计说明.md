# 拾光相机 · 手绘功能稿

[查看四屏总览](00-手绘相机功能总览.png)

本轮以 16:9 横屏经典旁轴机舱做四张 1920 × 1080 静态原型。纸纹、铅笔描边、排线、手写标题和朱红水彩快门用于相机外壳和控件。取景内容延续写实胶片摄影，和绘本里的纸质贴纸相区分。

| 界面 | 功能安排 |
| --- | --- |
| [默认取景](01-手绘相机-默认取景.png) | 默认进入普通模式。焦段和曝光读数贴近取景窗，画幅、网格、闪光、翻转、快门和相册位于右手侧。顶部可切机舱、模式或绘本。 |
| [换卷预览](02-手绘相机-换卷预览.png) | 从当前胶卷标签打开。原位对照同一构图，「当前使用」与试看的胶卷分开标记。选定后使用这卷，或者继续调配方。 |
| [专业参数](03-手绘相机-专业参数.png) | 示例显示自动曝光状态。曝光补偿和色温是可调项，ISO 与快门速度是读数。切到手动曝光可调 ISO 和快门。取景中的对焦和测光各有标记。 |
| [贴纸识别](04-手绘相机-贴纸识别.png) | 保持快门位置，用边框标出识别到的主体，标签显示「台灯」。按下快门进入原片和贴纸的对照预览。 |
