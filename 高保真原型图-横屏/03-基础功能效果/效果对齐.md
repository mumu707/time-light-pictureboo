# 基础功能与横屏效果

[查看三步效果对照](01-基础功能横屏效果对照.png) · [查看落位关键帧](02-贴纸落位与水彩晕染.png)

| 基础操作 | 画面应该让玩家看见什么 |
| --- | --- |
| 打开相机，拍下日常物件 | 中央是真实取景，右侧是快门和相册。拍下后，写实原片进入专属相册。 |
| 从专属相册的照片提取主体 | 双页并排显示原片和带模切白边的水彩贴纸。主操作是收入贴纸夹。提取不限次。 |
| 从贴纸夹取出贴纸，放进书页 | 同一黑白跨页里出现这件物品，彩色贴纸从落点向邻近纸面晕染。底部提示已摆放。 |

**可选分支**。非餐饮贴纸可以消耗每日唤灵印记。唤醒会加上折纸底座和情绪气泡，便于和普通装饰贴纸区分。

**预览范围**。展示贴纸放置前与放置后两个静态状态。相机沿用横屏取景稿，提取预览调整了主次操作，落位画面由内置 ImageGen 生成后合成到剧场界面。
