# 拾光立体书 · 精灵文字与对话需求

玩家能从精灵说的话看出它的性格、正在做的事和接下来的心愿。点精灵打开精灵卡，再点「聊聊」开始对话。「任务」提供当前书页的心愿和小游戏入口，心愿继续由精灵实际走到摆件旁并互动完成。

## 文案规模与角色口吻

[精灵台词库](精灵台词库.csv) 含 600 条独立中文台词，每种主性格 200 条。初见与重逢、散步与巡查、安静角落、玩具与游戏、植物观察、食物与分享、心愿与完成、偏好与避让、搬家与翻页、同伴与休息各 20 条。下文的分支对话另计。

| 主性格 | 表达习惯 | 选句偏重 |
| --- | --- | --- |
| 好奇 | 先观察，再提一个具体问题 | 路径、细节、结构、对比 |
| 活跃 | 先说行动，常邀请一起试 | 步调、游戏、接力、休息 |
| 敏感 | 先确认距离、声音或光线，再表达感受 | 安静、边界、等待、陪伴 |

现有精灵有好奇、活跃、敏感三个分值。取最高值作为主性格，同分时按好奇、活跃、敏感依次判定。同一精灵用原有固定种子选句。灯绒、雨芽等原住民和实拍唤醒的精灵共用台词库。章节、姓名、摆件名只从已显示的数据读取，生成句子时保持原有的独立名称。

## 情境与触发

| 情境 | 触发条件 |
| --- | --- |
| 初见与重逢 | 首次点开、跨会话再次点开或唤醒 |
| 散步与巡查 | 已完成一段路，或遇到阻挡并改道 |
| 安静角落、玩具、植物、食物 | 精灵走到对应摆件旁并实际开始互动 |
| 心愿与完成 | 玩家主动查看心愿，或精灵刚完成互动并记入心愿 |
| 偏好与避让 | 精灵靠近喜欢的摆件，或实际绕过回避物 |
| 搬家与翻页 | 搬家成功并已加载新书页，或玩家打开精灵当前所在的书页 |
| 同伴与休息 | 两只精灵已在彼此附近，或精灵进入休息状态 |

CSV 的「情境」用于筛选。接入时给每条台词补充触发子类。需要已发生事实的句子增加相应条件，例如到达摆件、存在同伴、访问过当前页或实际找到替代路径。把心愿请求、路途反馈、完成反馈分别标记，选句先核实条件，再按性格抽取。没有合适句子时退到同情境的通用句，最后使用无事实假设的问候。玩家主动对话优先于环境对白，翻页、拖动、遮挡和弹窗期间暂停环境对白。

同一精灵的最近 8 条台词去重，当前画面一次只展示一条环境对白，同一精灵两次主动冒泡间隔至少 25 秒。环境对白 4–6 秒后淡出。玩家点开的对话停留到主动关闭，选项按钮支持键盘和触屏。开启减少动态效果时直接显示和切换文字。正文按窄屏自然换行。句子保持一到两句，长对话拆成短轮次。

## 对话结构与首批脚本

「聊聊」默认给「今天怎么样」「你想要什么」「聊聊这一页」三个选项。选择后显示精灵回复，可继续一问或结束。心愿对话提供「查看任务」，移动、改名、摆放等游戏操作保留原有入口。环境对话由已存在的互动事件触发。关闭对话后精灵继续原有活动，聊过天不自动完成任务。

| 编号 | 玩家选项或触发 | 精灵回复 | 下一步 |
| --- | --- | --- | --- |
| D01 好奇 | 今天怎么样 | 我找到一条会把我带回原处的小路。你想陪我走走吗？ | 「你注意到了什么」→「从另一头回来，影子就换边了。」 |
| D02 好奇 | 你想要什么 | 我想看看这页的植物。叶尖是不是会朝着亮处？ | 「查看任务」→ 打开对应心愿 |
| D03 好奇 | 聊聊这一页 | 从书脊往两侧走，纸纹也跟着变了。 | 「你最想看哪里」→「我想先看看布景后面那条路。」 |
| D04 活跃 | 今天怎么样 | 我热完身了。今天想找一条能跑完再回来歇脚的路。 | 「先歇一会儿」→「好，我到下一段路口等你。」 |
| D05 活跃 | 你想要什么 | 我想试一个玩具。把它摆在能绕过去的地方，我就有位置转身了。 | 「查看任务」→ 打开对应心愿 |
| D06 活跃 | 聊聊这一页 | 这页有好几个转角。下次你来，我带你走另一边。 | 「你先走吧」→「行，我先把路认熟。」 |
| D07 敏感 | 今天怎么样 | 今天想走慢一点。你愿意在这里和我待一会儿吗？ | 「我陪你」→「好，我们先听听这里的声音。」 |
| D08 敏感 | 你想要什么 | 我想要一个安静的角落，坐着也能看到出口。 | 「查看任务」→ 打开对应心愿 |
| D09 敏感 | 聊聊这一页 | 这里的光有一点亮，我喜欢靠布景那一侧。 | 「我们去那边」→「等我站稳，再一起过去。」 |
| D10 好奇与活跃 | 两只精灵在玩具旁相遇 | 好奇「你刚才从哪边绕过来的？」活跃「外侧。我再走一次，你看脚下。」 | 两轮后各自恢复路线 |
| D11 敏感与好奇 | 两只精灵停在安静角落 | 敏感「我想在这里歇一会儿。」好奇「好，我等你想说的时候再问。」 | 停留期间让出入口 |
| D12 活跃与敏感 | 一只精灵停下休息 | 活跃「要一起去看看前面吗？」敏感「我再坐一会儿。你回来时告诉我。」 | 各自继续原活动 |

D01–D12 是写法和轮次参考。实际心愿回复读取当前心愿类型，植物、玩具、背景和食物各有对应语句。涉及窗、池、灯、风铃等场景细节的回复只在对应场景且靠近相关物件时使用。

## 内容接口与验收

- 文案记录包含稳定编号、主性格、情境、触发子类、条件和台词。对话记录包含稳定编号、入口、说话者、选项、下一节点和结束动作。开发时从审阅通过的表格导入内容。存档记录已聊过的节点和最近台词编号，旧存档默认空记录。
- 校验 600 条台词编号和正文唯一，每种性格恰有 200 条，每个情境恰有 20 条。抽查三类精灵在不同场景的口吻、过去时和事实条件。
- 对话验收覆盖首次见面、重逢、任务跳转、同伴对话、关闭恢复活动、键盘操作、缩放后文字布局、减少动态效果和离线可用。验证对话不会自行发放奖励、改变满意度或触发重复心愿。
