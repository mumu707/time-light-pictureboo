# 拾光 · 制作与交接手册

适用对象为美术、策划、前端、服务端和测试同事。当前交付是可玩的本地 Web 原型。七章原画已确认方向，模型细化按本手册分批进入制作。情绪符号基础状态已接入原型，600 条台词与 12 组对话脚本进入内容标注和接入阶段。

## 产品与版本基线

核心体验从拍照开始。玩家用胶卷拍下一件东西，在相册提取它并选定摆件用途，带到立体书里布置。精灵会自己走过去互动，留下心愿与喜好记录。图鉴提供物体观察和收藏，游戏提供空间布置、居民和小游戏。

| 模块 | 当前可交接的内容 | 下一批制作 |
| --- | --- | --- |
| 相机 | 实时取景、胶卷与镜头、相纸和画幅、快门和定时、取景贴纸、成片保存 | 设备兼容矩阵、首拍和首次授权文案 |
| 相册与图鉴 | 浏览、导入、分享、收藏与恢复、本地抠图、四种用途、智谱识别与对比确认 | 用途预览、低置信度分割提示、来源缺失状态统一 |
| 立体书 | 七章直接进入、厚页与纸铰链、拖动旋转、捏合缩放、桌面滚轮、任务 | 按审查原画替换关键纸模，补远景、地表和行走通路 |
| 家园与精灵 | 直立摆件、碰撞与附着、寻路、唤醒、搬家、心愿计分与基础符号 | 对话接入、统一符号素材、状态可读性和大型场景性能 |
| 生态小游戏 | 溪流纸舟、萤火连线、风铃复奏、潮汐拾贝及首通摆件 | 与场景中的模型入口呼应，补动画、音效和新手反馈 |

版本关系以当前原型为准。满意度记录居民心愿进度，七个章节从首次进入起可选。相机、相册和游戏沿用同一个手机模拟容器。桌面预览基准为 390 × 844，真机按可用屏幕展示。

## 美术拆解与出件

[七章原画审查索引](场景原画/审查索引.md) 对应各章概念。先以灰模确定轮廓、站位、折叠范围和通路，再做纸面质感和小件。原画中的结构可按交互要求取舍，建模验收以手机镜头下的识别度、碰撞和折叠为准。

| 章节 | 主模型 | 地表与背景 | 道具和可动件 | 联调要点 |
| --- | --- | --- | --- | --- |
| 暖窗书房 | 框窗、书桌、书架、陈列柜 | 蜂蜜色窗光、格纹地面、纸毯与远墙 | 台灯、杯子、摊开书、靠垫、三种书堆 | 窗与书架分层折叠，桌脚占地可绕行，地毯保留可行走面 |
| 雨后花园 | 苔拱、育苗架、长椅 | 雨池、苔径、湿石、半透明雨滴 | 苗盆、落叶、小石和池面波纹 | 池边阻挡，拱下净空可走，叶片有折线与侧面 |
| 月光车站 | 候车亭、站钟、旧轨、行李台 | 靛蓝远景、暖灯、站前广场 | 票牌、箱子、短轨枕木、钟针 | 保持紧凑候车亭和短轨比例，站前保留精灵停靠区 |
| 苔石溪谷 | 桥、停舟岸、溪岸与浅滩 | 弯曲水带、苔石径、层叠岩壁 | 纸舟、三码头浮标、板桥与苔块 | 桥面净宽通过角色测试，水面阻挡，纸舟玩法配色与场景一致 |
| 萤火湿地 | 观灯台、芦苇湾、岸边栈道 | 静水岸、倒影和暮色 | 四盏可辨识灯、萤火颗粒、芦苇组 | 四灯靠形状和亮灭区分，注意手机色弱与远距离辨识 |
| 风铃高原 | 风铃棚、风车、望风台 | 草坡、风向旗和远山层 | 四个铃体、转轴、旗绳和草簇 | 铃声与视觉提示对应，风车转轴独立，旗绳留出折叠范围 |
| 星潮海岸 | 潮池、礁石湾、小灯塔 | 沙滩、水线和潮池层 | 三类贝壳、浮沫、灯罩 | 涨退潮用标记和形状提示，岸边动线清楚，灯塔避开常用摆件区 |

- **共用书本**交付封面、封底、布面书脊、页叠、翻动页、纸铰链和纸插片。现有每侧页叠 14 层，单页约 9.64 × 16.90 世界单位。场景构件、可动件与地表分离，平铺插槽和阴影接触面单独检查。
- **摆件底座**按背景宽脚撑、玩具插片、植物盆和食物托盘制作。保留照片轮廓和纸板侧边。每类交付正侧背参考、挂点和碰撞轮廓。贴在墙面时使用对应附着点。
- **模型交付约定**建议先交灰模截图和可编辑源文件，再交 GLB、贴图和挂点表。Three.js 原型当前使用程序生成几何，GLB 加载是后续接入项。新模型采用 Y 向上，局部原点放在落地中心或纸铰链上。表格记录对象名、世界坐标、占地宽深、挂点、是否可穿行及动画名。通用材质与同类小件优先复用，透明纸层与投影分别验证。
- **审查顺序**先看三视与 390px 实际取景，再看能否摆放、旋转、折叠和绕行。每章包含四个区域，画面空地留给玩家摆件。美术交付时同时标出保留的通道、需要阻挡的位置与装饰表面，开发联调时共用这份占地数据。

## 详细交互与验收实践

| 流程 | 用户操作与预期反馈 | 异常和边界 | 验收步骤 |
| --- | --- | --- | --- |
| 首次拍摄 | 打开相机、授权、换胶卷、按快门，从相册查看成片。胶卷选择留在弹出菜单内可连选，取景随选项变化 | 拒绝权限时可返回设置或浏览已有照片。补光与对焦依设备能力。定时中点取景可取消 | 拒绝一次并重试，切卷两次，检查菜单保持和成片效果，验证 3 秒定时取消 |
| 相册浏览 | 点相册进入独立页面。筛选、打开照片、滑动回看、导出或移入最近删除 | 取消导入返回相册，批量操作只改变选中项，恢复后保留成片 | 导入 PNG，切换筛选，批量删除后恢复，比较导出的原文件 |
| 提取摆件 | 照片详情点「提取贴纸」，先选背景、玩具、植物或食物。预览主体，点选或框选，确认保存 | 模型下载失败显示重试。离开后取消旧请求。保存前改用途复用抠图结果 | 确认选用途前未开始提取。框选后断网复用已加载模型。改用途再保存，查看收藏详情 |
| 识别图鉴 | 从提取结果或贴纸详情点「识别入图鉴」。核对名称、分类和观察。重复条目弹出新旧比较 | Key 缺失、限流、超时提供对应反馈和重试。保留当前条目时两张贴纸均留在收藏 | 用本机模拟接口分别走首次收录、更新、保留、超时。删除来源照片后打开图鉴 |
| 收藏进游戏 | 从贴纸或图鉴页点「进入游戏」。点击封面后纸模依次立起，从游戏返回恢复收藏页签 | 无 WebGL 2 时进入平面模式。减少动态效果时直接切换 | 从两个页签各进出一次，关闭 WebGL 2 后验证导航和摆件可用 |
| 镜头与翻页 | 拖空白处旋转，双指缩放，桌面滚轮缩放。下方翻页按钮和场景名负责换章 | 捏合从摆件上开始时撤销未提交拖动。翻页期间锁操作，模型先收拢再翻页 | 在 320px、390px 和桌面模拟框测试边缘、拖动、双指、最大缩放、重置与双向翻页 |
| 家园编辑 | 点「添加贴纸」选收藏或基础摆件。选中后移动、旋转、缩放、选表情或贴附，点「完成」恢复活动 | 旧收藏首次选用途。占地重叠或超界提示，停在最近有效位置。存储失败允许重试 | 各摆四种底座，拖到障碍，切到附着面再旋转，刷新核对角度和坐标 |
| 唤醒与搬家 | 从图鉴选择主体唤醒立体精灵。点精灵查看性格、心愿、喜好，选择住处 | 同来源重复唤醒打开已有卡。来源贴纸缺失时展示状态并跳过渲染 | 唤醒、重复唤醒、跨章搬家、刷新后重新找到它 |
| 心愿与任务 | 「任务」显示当前页心愿、全书满意度和小游戏。摆好对应物件并点完成。精灵到达后互动并显示符号 | 路不通时重新寻路。每位精灵每类首次心愿计 1 点，重复满足只更新互动反馈 | 先堵住路，观察反馈，再让出通路。核对完成记分和刷新后的记录 |
| 小游戏与奖励 | 当前章入口开小窗。纸舟选岔口、萤火记顺序、风铃听或看提示、潮汐退时拾贝 | 错选可重试，关闭回原书页，首通奖励写入收藏，重复通关复用同一记录 | 四章各走成功与重试。风铃静音也能完成。两次通关后刷新，收藏只有一份奖励 |
| 对话接入后 | 点精灵卡「聊聊」，从问候、心愿、章节三个选项进入，可续问或回任务 | 对话期间暂停自主活动，关闭后恢复。内容需要符合当前角色与场景条件 | 对同一角色多次对话确认去重。验证离线、键盘、情绪抢占和任务计分 |

### 小游戏逐步走查

| 玩法 | 当前操作顺序 | 反馈与重试 |
| --- | --- | --- |
| 溪流纸舟 | 看两侧浮标，逐次选择左或右岔口，通过三个浮标 | 选对后更新航段。撞岸显示回到起点。测试先撞岸一次，再完成三段 |
| 萤火连线 | 点开始，看灯位顺序，待选项出现后按顺序点灯，共三轮 | 错误后可重看该轮。测试第二轮故意选错，确认已过第一轮保留 |
| 风铃复奏 | 点开始，跟随四种铃的名称和声响，依序复奏三轮 | 可依可见提示完成。测试静音通关、播放期间退出、退出后重新开始 |
| 潮汐拾贝 | 等到显示「退潮」，点一次「拾取贝壳」，等下轮，累积三枚 | 涨潮或同一轮重复点击时显示等待。测试故意错过一轮，再完成余下次数 |

### 场景交互与模型联调

1. **定位**。美术标记模型的地面原点、纸铰链和可点击位置。前端用带调试框的灰模确认在默认镜头和最大侧转角时，点击位置与模型一致。
2. **占地**。策划划定阻挡、可行走和可摆放区域。精灵从左右两侧经过关键构件，玩家将小、中、大三种底座拖到边界。用同一份尺寸表对齐模型和判定。
3. **翻页**。给高构件和墙面摆件各放一件测试物，逐帧检查布景收拢、纸张翻转、下一章展开。碰撞检查同时覆盖正向、反向和目录跳转。
4. **交接记录**。每次审查记录章节、区域、对象、预期效果、实机截图和负责岗位。需要修改原画的项单独标注，确认后进入对应模型迭代。

## 精灵情绪符号与状态规则

当前原型使用文字符号，下一批美术用同一语义制作纸质图标。每个图标交付明暗两套可读预览、透明素材、中文说明和触发示例。以 24px 主体预览检查辨识，交付高分辨率透明图。颜色只辅助，轮廓和动作也要能区分。符号挂在精灵头顶，随视角移动，缩放时维持可读尺寸。屏幕阅读器从精灵按钮描述读取状态，避免持续播报每次短暂变化。

| 符号 | 状态 | 触发与时长 | 下一批图形与动作 |
| --- | --- | --- | --- |
| 💛 | 喜欢 | 已发现喜欢的摆件或表情，约 2.1 秒 | 心形纸片，轻跳一下 |
| 💧 | 不安 | 回避偏好命中，约 2.1 秒 | 小水滴，身体缩一下 |
| ❔ | 好奇 | 对改变的摆件作中性观察，约 2.1 秒 | 问号与小圆点，转头 |
| 🚧 | 暂时走不通 | 找不到可用路线时首次出现，约 2.4 秒 | 断开的小路，停住看两侧 |
| 😌 | 安心休息 | 走到背景摆件旁，约 2.6 秒 | 半闭眼，身体放低 |
| 🎉 | 玩得开心 | 走到玩具旁，约 2.6 秒 | 三片纸花，短跳 |
| 🌱 | 看植物 | 走到植物旁，约 2.6 秒 | 两片幼叶，俯身观察 |
| 😋 | 品尝 | 走到食物旁，约 2.6 秒 | 托盘与笑眼，连续点头 |
| ✨ | 心愿实现 | 到达并完成当前心愿，约 3.2 秒 | 双星亮一下，任务进度更新 |
| ♪、👀、💤 | 前往、观察、打盹 | 在对应活动持续时展示 | 单音符、眼睛、睡眠线条 |
| 🏞️、🧸、🌿、🍓 | 背景、玩具、植物、食物心愿 | 精灵空闲或自由走动时显示，可点开看文本 | 四种纸签，共用边框 |
| 👋、💬、🤝 | 招呼、对话、同伴交流 | 对话接入后，仅在相关事件发生时出现 | 挥手、气泡、并排双纸片 |

当前优先级为心愿完成与短反馈、正在进行的活动、待办心愿。对话接入后，玩家主动打开的对白优先展示。关闭对话回到精灵当前状态。多只精灵靠得太近时，下一批优先保留最近交互的精灵气泡，再处理其余符号的避让。减少动态效果时使用静态图标和文字。动作、台词、任务计分各用独立事件，避免单纯换表情时误加分。

## 分工、接口与开发顺序

| 批次 | 责任与交付 | 进入下一批的条件 |
| --- | --- | --- |
| 1 · 样板 | 美术先做暖窗书房的书本、书桌和窗。策划标注任务入口、通路、挂点。前端接入一套样板，测试检查折叠与撞体 | 390px 读得清，模型能翻页、能绕行、能摆放 |
| 2 · 七章资产 | 美术按上表制作，其余六章按共用材质和部件复用。前端接碰撞与活动点。测试在三个窗口尺寸逐章走查 | 七章模型与原画的关键构图吻合，场景切换能恢复状态 |
| 3 · 精灵内容 | 策划为 600 条文案补触发子类和事实条件，确认 12 组脚本。美术制作情绪图标。前端接台词、对话、气泡和去重 | 三种性格各 200 条可用，首见、心愿、同伴对话和任务跳转均验收 |
| 4 · 交付验证 | 前端与测试完成真机、多指、无 WebGL 2、低动效和性能检查。服务端与测试核对识别状态及凭据处理 | 保存、加载、迁移、奖励去重、导出和关键路径回归通过 |

- 相册、贴纸和图鉴使用同源 IndexedDB。书页坐标、摆件用途、旋转、精灵、满意度和奖品保存在本机。资源按稳定 ID 关联，旧照片与旧摆件继续走原有迁移。情绪瞬时状态不写存档，后续对话只存已见节点和最近台词 ID。
- 智谱 Key 由本地 Node 服务读取。只有用户点击「识别入图鉴」才请求模型。本地抠图和精灵文字离线可用。项目启动后使用 `http://localhost:3468/`，接口详情见[图鉴配置](../camera/贴纸与图鉴配置.md)。
- 每批用同一套样张、历史存档和场景走查数据。自动回归运行 `npm test`。真机验收另记录设备、浏览器、摄像头权限、触控、场景帧率和加载时间。待样板定型后按实测决定贴图和模型预算。

相关资料见[精灵文字与对话需求](精灵文字与对话需求.md)、[精灵台词库](精灵台词库.csv)和[场景原画审查索引](场景原画/审查索引.md)。
