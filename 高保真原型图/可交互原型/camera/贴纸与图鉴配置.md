# 贴纸与图鉴

照片详情中的「提取贴纸」使用本地 U²-NetP 模型。保存贴纸后，选择「识别入图鉴」才会把选中主体和缩小的上下文图片提交给 DeepSeek (`dsv4.1flash`)。

## 启动

在可交互原型目录执行以下命令。

```powershell
npm.cmd install
npm.cmd run prepare:discovery
node server.js 3468
```

已随项目提供模型、WASM 和授权文件。`prepare:discovery` 用于重新准备这些文件，会校验上游模型摘要，并生成供浏览器校验的 SHA-256 清单。

## 配置 DeepSeek (dsv4.1flash)

打开相册，依次选择「收藏册」「进入游戏」「设置」，输入 DeepSeek API Key 并点击「保存配置」。保存后回到收藏册即可识别。游戏设置可以替换或清除已保存的 Key。

本机服务将页面保存的 Key 存在当前系统用户的配置目录中。也可以在启动 Node 服务的 PowerShell 窗口中设置环境变量，作为未通过页面配置时的备用来源。默认接口为 `https://api.deepseek.com/chat/completions`。

```powershell
$env:DEEPSEEK_API_KEY = Read-Host '输入 DeepSeek API Key' -MaskInput
node server.js 3468
```

凭据只在 Node 服务读取（纯客户端 / Android 离线封装环境下则从本地设置读取用户输入）。前端通过 `POST /api/identify-object` 提交 `subjectImage` 和 `contextImage` 两个 JPEG/PNG data URL。成功响应包含 `name`、`category`、`tags` 和 `observation`。未配置返回 503，识别限流返回 429，等待 45 秒超时返回 504。

如果 3468 上已有预览服务，请在原服务窗口按 Ctrl+C，再用上面的命令启动。使用同一个预览地址即可继续访问原有的相册和贴纸。

[DeepSeek API 文档](https://api-docs.deepseek.com/)

## 数据与验证

照片、贴纸与图鉴均保存在浏览器的 `shiguang-camera` IndexedDB 中。图鉴更新当前展示关联，贴纸独立保存。来源照片进入最近删除后，图鉴仍使用保存的完整合成图展示。

```powershell
npm.cmd run test:camera
npm.cmd run test:discovery
```

图鉴测试使用真实本地抠图模型和本机模拟的 DeepSeek 接口响应，覆盖流程与接口错误。配置 DeepSeek API Key 后，可从页面执行「识别入图鉴」验证真实识别。

模型来自 [U²-Net](https://github.com/xuebinqin/U-2-Net)，ONNX 权重来自 [rembg](https://github.com/danielgatis/rembg)。运行时来自 [ONNX Runtime Web](https://onnxruntime.ai/docs/tutorials/web/)。授权文件位于 `camera/assets/inference/`。
