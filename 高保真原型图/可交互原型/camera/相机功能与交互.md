# 拾光相机功能与交互

拾光是一台竖屏胶片相机。打开后直接取景，选好胶卷即可按快门，拍完从左下角回看。取景、换卷和快门在同一屏上，石墨线条和纸标区分机身与控件。

| 位置 | 功能 |
| --- | --- |
| 顶栏 | 开启设备相机或切换实体镜头、特效镜头、画幅、补光、设置。 |
| 取景小窗 | 点击顶栏控件，在取景窗顶部展开对应选项。选择即时生效，小窗可继续操作。点击小窗外、原入口或关闭按钮收起。 |
| 取景窗 | 当前胶卷实时预览、成片边界和构图网格。设备支持时可点击取景窗对焦。 |
| 取景下方 | 常用取景倍率。 |
| 底栏 | 相册、固定快门和当前胶卷。 |
| 胶卷栏 | 点右下角，在倍率和快门之间展开。上排切换分类，下排横滑手绘胶卷罐。「胶片」分类从常用卷开始，可浏览全部 32 卷。点选立即更新取景，胶卷栏保持展开。点击栏外或再次点击右下角收起。 |

## 拍摄和回看

- 左上角开启实时相机，再次点击可从浏览器报告的设备中选镜头。开启过相机且浏览器仍授予权限时，再次打开会直接恢复实时取景。补光、点按对焦和低倍率由设备能力决定，普通倍率也可使用取景裁切。
- 画幅支持 4:3、1:1、16:9、65:24 和半格。半格先拍第一格，再拍第二格生成双联成片。拍完第一格可重拍，离开半格画幅会清掉暂存。
- 顶部「镜头」可选原镜头、鱼眼、凹镜、凸镜、哈哈镜或偏色。效果实时出现在取景窗，并应用到成片。半格两张分别记录各自拍摄时的胶卷与镜头效果。
- 设置中可选择 JPG 或 PNG、3 秒或 10 秒定时、构图网格和快门声音。轻触取景窗中的倒计时可取消这次拍摄。
- 相册按日期以三列展示，支持筛选全部、收藏、相机拍摄、导入和最近删除。点开大图可左右滑动、查看拍摄信息或切换原片。分享菜单提供导出；支持文件分享时也可调出系统分享。
- 点「选择」或长按照片可以多选，进行收藏或移到最近删除。最近删除里的照片可单张或批量恢复。左下角相机按钮返回取景。
- 可从设备选择 JPG、PNG 或 WebP。确认导入后保存原文件。

## 照片保存

按下快门时选中的胶卷和镜头效果会写入成片，同时保留构图后尚未调色的原片。相册里的成片和原片均为只读，收藏、删除和恢复只更新相册状态。升级后旧照片仍可回看和导出。

## 交互参考

- NOMO CAM 用专用按钮进入机型选择。拾光用快门旁的当前胶卷进入选择，拍照主屏留给取景。 [NOMO CAM](https://play.google.com/store/apps/details?id=com.blink.academy.nomopro)
- mood.camera 把随手直出作为默认体验。拾光采用可直接拍摄的默认胶卷，记住上次选择，并将选中胶卷的色调应用到实时取景。 [mood.camera](https://apps.apple.com/us/app/mood-camera/id6472954208)
- iPhone 照片的方格和筛选用于组织照片库；Google 相册的长按多选和垃圾桶恢复用于批量管理。 [iPhone 照片](https://support.apple.com/guide/iphone/browse-your-photo-library-iph7d24753a5/ios) · [Google 相册](https://support.google.com/photos/answer/6128858?co=GENIE.Platform%3DAndroid&hl=en)

## 本地运行与验证

在「高保真原型图/可交互原型」目录运行 `node server.js`，打开 `http://localhost:3456/camera/`。浏览器相机需要安全上下文。打开样张可以直接体验拍摄和相册。

运行 `npm run test:camera`，可验证旧相册迁移、分页和返回位置、模拟设备拍摄、半格与定时取消、收藏、滑动浏览、原样导入、导出和删除恢复。测试会比对恢复前后的成片和原片校验值。
