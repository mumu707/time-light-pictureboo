# 《拾光绘本：万物有灵》随手拍拟物手绘相机详细设计规范

---

## 一、 设计核心理念：随手拍 · 纯拟物 · 手绘质感

本规范基于“**随手拍、零复杂参数、极致拟物手感、海量胶卷体验**”的核心定位，对相机系统进行全面重构。
摒弃一切复杂的数码滑杆与二级参数菜单，还原胶片时代“选一卷胶卷，装进相机，调节焦段与画幅，按动快门即得大片”的纯粹乐趣。

### 核心设计原则
1. **随手拍（Snap-and-go）**：0.3 秒即开即取景，拍完零等待秒存相册，支持连续抓拍，绝不打断拍照心流。
2. **纯拟物化（Skeuomorphic）**：所有控件皆为物理实体形态——手绘黄铜快门钮、机械齿轮拨盘、物理遮光帘片、胶卷仓锁扣。
3. **手绘纸艺质感（Hand-drawn Paper & Ink）**：机身采用温暖棉浆纸底纹、炭黑手绘墨线、复古金属光泽与露铜装饰，兼具专业胶片机的机械感与绘本插画的温度。
4. **胶卷即灵魂（Film is Key）**：无需用户手动微调颗粒与色温，每款胶卷出厂即由专业色彩工程调配至巅峰状态。

## 二、 主界面拟物布局与核心物理控件 (Layout & Controls)

相机主界面采用“经典手绘旁轴机身”为视觉载体，单手即可完成全部操作：

```

|  [闪光拨钮]        [画幅拨片 3:4]        [累计快门 0108]  |
|  (关/自动/开/直闪)  (3:4/1:1/16:9/XPAN)  (机械滚轮翻字)    |
+-------------------------------------------------------+
|                                                       |
|                     【拟真取景框】                      |
|                                                       |
|       * 随画幅拨片物理滑入遮光金属帘片                  |
|       * 双击画面触发中心微黄斑点测光/对焦               |
|       * 贴纸识别轻框（仅特殊模式）                      |
|                                                       |
+-------------------------------------------------------+
|  [镜头翻转]        [28mm | 50mm | 85mm]                 |
|  (物理微棱镜)       (三档手绘定焦金属拨片)               |
+-------------------------------------------------------+
|  [底片夹相册]          【手绘快门钮】         [拟物胶卷仓] |
|  (缩略图齿孔卡)        (朱红搪瓷/机械震动)     (轻向上滑抽屉)|
+-------------------------------------------------------+
```

### 2.1 六大核心物理控件设计

| 物理控件名称 | 视觉形态与手绘质感 | 交互操作方式 | 出片与音效震动反馈 |
| :--- | :--- | :--- | :--- |
| **① 手绘快门按键 (Shutter)** | 炭黑机身右下角的朱红搪瓷快门扣，附带细腻高光与金属底座 | 单击即拍；支持长按连拍 3 张 | 清脆机械快门升降声（`咔嚓-呲`）+ 线性马达清脆微震；计数器翻字滚动 `+1` |
| **② 拟物胶卷仓 (Film Latch)** | 位于右侧底部的胶卷暗盒插槽，露出一小截当前胶卷的手绘彩色金属筒身与型号代号 | 向上轻推或点击，平滑拉出全尺寸【拟物胶卷抽屉】 | 伴随卡榫开启清脆机械声（`Click`），露出海量胶卷陈列 |
| **③ 闪光灯拨钮 (Flash Lever)** | 顶部左侧的手绘金属拨杆，带 4 档物理刻度 | 单指拨动切换：`OFF(关)` → `AUTO(自动)` → `ON(强开)` → `Y2K(冷白直闪)` | 拨动有阻尼段落感；开启时取景器边角泛起闪光电容充能提示微光 |
| **④ 经典定焦拨片 (Lens Lever)** | 取景器正下方的弧形手绘金属刻度条，标刻 `28mm`、`50mm`、`85mm` | 单指轻拨滑入对应卡槽 | 伴随镜头镜筒机械转动微声；取景器视野平滑变焦（28mm 广角 / 50mm 人眼标准 / 85mm 人像特写） |
| **⑤ 画幅机械拨片 (Ratio Shutter)** | 机顶中央的小型遮光旋钮，标刻 `3:4`、`1:1`、`16:9`、`XPAN`、`HALF` | 点击或拨动切换画幅 | **物理遮光帘动效**：取景窗两侧/上下伴随手绘金属挡片物理滑入，实时裁切取景框，机械感十足 |
| **⑥ 底片夹相册 (Film Album)** | 左下角带胶片齿孔与最新成片缩略图的小卡片 | 点击推开底片暗房相册 | 伴随纸张滑出翻页声，直接翻看所有胶片大片 |

## 四、 极简出片流程与相纸边框 (Shooting Flow & Borders)

```
[拿起相机] ──> [选卷 / 焦段 / 画幅] ──> [按下快门] ──> [清脆机械快门声 + 震动]
                                                               ↓
                                                [成片秒存，计数器+1]
                                                (用户可继续快速连拍)
                                                               ↓
                                                [随时点击左下角底片夹相册查看]
```

### 4.1 随手拍零等待逻辑
1. **即拍即走**：按动快门瞬间完成拍照渲染并写入相册，取景画面仅闪烁一次极轻微的拟真机械快门叶片闭合黑帧（0.08 秒），绝不卡顿，绝不打断下一次快门。
2. **机械计数器（Mechanical Shot Counter）**：机顶右侧的滚轮计数器从 `0001` 开始随快门累加翻转，模拟真实胶卷计数盘跳字。
3. **三种可选相纸装帧（相册内随时一键切换）**：
   - **纯净原片（Borderless Film）**：全画幅满版无边框，最适合直接发社交媒体朋友圈；
   - **底片印字边框（Film Rebate & Sprocket）**：四周带有经典柯达/富士黑色底片齿孔与胶卷代号帧号；
   - **拍立得/手帐框（Classic Polaroid Frame）**：经典的宽白边拍立得相纸，右下角带有橙色手写体日期。

## 五、 拟物底片夹相册与“绘本/精灵”的优雅连接

相册是随手拍的终点，也是通往《拾光绘本》世界的入口，但**绝不喧宾夺主**：

```
+-------------------------------------------------------------+
|  [< 相机]           【 拾 光 暗 房 底 片 夹 】        [批量导出 v] |
+-------------------------------------------------------------+
|                                                             |
|   +-------------------+             +-------------------+   |
|   |   [雨天窗边台灯]   |             |   [街角拉花拿铁]   |   |
|   |                   |             |                   |   |
|   |  Gold 200 · 3:4   |             |  Pro 400H · 1:1   |   |
|   |  2026.11.11 10:25 |             |  2026.11.11 10:48 |   |
|   +-------------------+             +-------------------+   |
|       ( 提取贴纸 ◈ )                     ( 提取口粮 ☕ )      |
|                                                             |
+-------------------------------------------------------------+
|  [当前已收录贴纸 18/100]        [翻开《拾光绘本》立体书 ➔]   |
+-------------------------------------------------------------+
```

1. **底片暗房翻看**：像从底片保护袋中抽出的透明胶片夹，手指滑动翻阅每张写实大片，支持原图一键保存到手机系统相册或分享。
2. **轻量手绘印章【提取贴纸 ◈】**：
   - 每张照片右下角仅保留一枚极其精致的手绘小印章。
   - 随手拍爱好者可以完全不点它，把它当作纯粹好用的胶片冲印相册；
   - 想玩绘本的玩家点击印章，即可一秒在相片旁生成手绘白边贴纸，并提示今日是否有【注入灵魂】机会，顺畅滑入立体绘本剧场。
